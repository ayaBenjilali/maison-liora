# Maison Liora

Responsive web and mobile-friendly cafe website for Maison Liora, built with Next.js, TypeScript, Tailwind CSS, Framer Motion, and Lucide icons.

## Live Website

View the site here:

https://maison-liora.vercel.app/

## About

Maison Liora is a premium showcase website concept for a specialty cafe in Casablanca. It is designed for desktop and mobile browsers, with responsive sections, elegant visuals, smooth motion, menu highlights, gallery content, and clear reservation calls to action.

The project presents the cafe's identity, story, coffee specialties, brunch offering, customer reviews, reservation flow, location details, and footer content in a refined modern web experience.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Next.js, usually `http://localhost:3000`.

## Build

```bash
npm run build
```
